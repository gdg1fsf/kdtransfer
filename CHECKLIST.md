# ✅ Чек-лист запуска KD Transfer

Используйте этот чек-лист для проверки перед запуском сайта в продакшен.

## 📋 Обязательные настройки

### 1. Telegram бот
- [ ] Создан бот через @BotFather
- [ ] Получен токен бота (формат: `1234567890:ABCdefGHIjklMNO`)
- [ ] Получен Chat ID (формат: `123456789`)
- [ ] Токен и Chat ID добавлены в `index.html` или `send-order.php`
- [ ] Отправлено тестовое сообщение боту (Start)
- [ ] Бот отвечает на сообщения

### 2. Форма заказа
- [ ] Форма отображается корректно
- [ ] Все поля работают (текст, даты, выпадающие списки)
- [ ] Валидация обязательных полей работает
- [ ] Тестовая заявка успешно отправлена
- [ ] Заявка пришла в Telegram с правильным форматированием
- [ ] Сообщение об успехе показывается после отправки

### 3. Контент сайта
- [ ] Логотип загружен (`images/logo.png`)
- [ ] Скриншот Telegram профиля загружен (`images/telegram-profile.png`)
- [ ] Ссылки на Telegram обновлены (замените `@kdtransfer` на ваш username)
- [ ] Маршруты актуальны
- [ ] Цены обновлены (если указываете конкретные)
- [ ] Контактная информация верна
- [ ] Отзывы обновлены (или удалены примеры)

## 🔒 Безопасность

### Базовая
- [ ] `.htaccess` файл загружен на сервер

- [ ] Конфигурационные файлы (`.md`, `.json`) недоступны извне

### Продвинутая (рекомендуется)

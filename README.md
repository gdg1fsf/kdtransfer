- 🎨 Современный дизайн с анимациями

## 🚀 Быстрый старт

### 1. Настройка Telegram бота

**Важно:** Перед использованием формы заказа нужно настроить Telegram бота.

📖 **Подробная инструкция:** [TELEGRAM_BOT_SETUP.md](./TELEGRAM_BOT_SETUP.md)

**Кратко:**
1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Узнайте свой Chat ID через [@userinfobot](https://t.me/userinfobot)
4. Откройте `index.html` и найдите (примерно строка 537):
   ```javascript
   const TELEGRAM_BOT_TOKEN = 'YOUR_BOT_TOKEN';
   const TELEGRAM_CHAT_ID = 'YOUR_CHAT_ID';
   ```
5. Замените на свои данные

### 2. Запуск сайта

Просто откройте `index.html` в браузере!

Или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# PHP
php -S localhost:8000
```

Затем откройте: `http://localhost:8000`

## 🎨 Кастомизация

### Цвета

Откройте `style.css` и измените переменные в `:root`:

```css
:root {
  --black: #000000;
  --white: #ffffff;
  --gray-400: #999999;
  /* ... остальные цвета */
}
```

### Логотип

Замените файлы в папке `images/`:
- `logo.png` — ваш логотип (рекомендуется 200x200px)
- `telegram-profile.png` — скриншот вашего Telegram профиля

### Контент

Все тексты находятся в `index.html`:
- Маршруты — секция `<!-- ROUTES -->`
- Преимущества — секция `<!-- ADVANTAGES -->`
- Отзывы — секция `<!-- REVIEWS -->`

## 🚀 Деплой

### GitHub Pages (бесплатно)
1. Создайте репозиторий на GitHub
2. Загрузите все файлы (кроме PHP файлов, если не используете)
3. Settings → Pages → Source: main branch
4. Готово! Сайт доступен по адресу: `https://username.github.io/kdtransfer`

⚠️ **Важно:** GitHub Pages не поддерживает PHP. Используйте JavaScript версию или другой хостинг.

### Netlify (бесплатно)
1. Перетащите папку на [netlify.com/drop](https://netlify.com/drop)
2. Или подключите GitHub репозиторий
3. Для PHP используйте Netlify Functions

### Vercel (бесплатно)
```bash
npx vercel
```
Для PHP создайте `/api` папку с serverless функциями.

### Обычный хостинг с PHP
1. Загрузите все файлы через FTP или панель управления
2. Настройте `send-order.php` (см. [PHP_SETUP.md](./PHP_SETUP.md))
3. Проверьте права доступа (755 для папок, 644 для файлов)
4. Активируйте SSL сертификат
5. Готово!

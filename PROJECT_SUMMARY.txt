1️⃣  СОЗДАЙТЕ TELEGRAM БОТА
   → Откройте: https://t.me/BotFather
   → Команда: /newbot
   → Сохраните токен

2️⃣  УЗНАЙТЕ CHAT ID
   → Откройте: https://t.me/userinfobot
   → Нажмите: Start
   → Сохраните ID

3️⃣  НАСТРОЙТЕ САЙТ
   → Откройте: index.html (строки 537-538)
   → Вставьте токен и Chat ID
   → Сохраните файл

4️⃣  ЗАПУСТИТЕ
   → Откройте index.html в браузере
   → Или: python -m http.server 8000

5️⃣  ПРОВЕРЬТЕ
   → Заполните форму заказа
   → Отправьте заявку
   → Проверьте Telegram

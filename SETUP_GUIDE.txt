🚀 БЫСТРЫЙ СТАРТ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  СОЗДАЙТЕ TELEGRAM БОТА (2 мин)
   
   → Откройте: https://t.me/BotFather
   → Отправьте: /newbot
   → Сохраните токен (например: 1234567890:ABCdefGHI...)

2️⃣  УЗНАЙТЕ CHAT ID (1 мин)
   
   → Откройте: https://t.me/userinfobot
   → Нажмите: Start
   → Сохраните ID (например: 123456789)

3️⃣  НАСТРОЙТЕ САЙТ (2 мин)
   
   → Откройте файл: index.html
   → Найдите строки (около 537-538):
   
   const TELEGRAM_BOT_TOKEN = 'YOUR_BOT_TOKEN';
   const TELEGRAM_CHAT_ID = 'YOUR_CHAT_ID';
   
   → Замените на свои данные:
   
   const TELEGRAM_BOT_TOKEN = '1234567890:ABCdefGHI...';
   const TELEGRAM_CHAT_ID = '123456789';
   
   → Сохраните файл (Ctrl+S)

4️⃣  ЗАПУСТИТЕ САЙТ (30 сек)
   
   → Просто откройте index.html в браузере
   ИЛИ
   → python -m http.server 8000
   → Откройте: http://localhost:8000

5️⃣  ПРОВЕРЬТЕ (1 мин)
   
   → Прокрутите до формы заказа
   → Заполните тестовыми данными
   → Нажмите "Отправить заявку"
   → Проверьте Telegram — заявка должна прийти!
